# Security Policy

## Supported versions

fabDev is currently in an unsigned Community beta. Security fixes are applied to the latest published version only.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, private keys, customer data, internal domains, IP addresses, or exploit details in a public issue.

Use GitHub's private vulnerability reporting from the repository **Security** tab. If private reporting is unavailable, open a public issue containing only a request for a private contact channel and no sensitive technical details.

Include the affected version, platform, reproduction steps, impact, and any suggested mitigation in the private report. Please allow the maintainers time to investigate before public disclosure.

## Unsigned builds

Community packages are not signed with an Apple Developer ID or a Windows code-signing certificate. Verify every downloaded package against the SHA-256 checksum published with its GitHub Release before installation.
